# 📈 Stock Portfolio Tracker

A simple web-based Stock Portfolio Tracker built using Python and Flask.

The application allows users to select stocks, enter quantities, calculate individual investments, and view the total portfolio value using manually defined stock prices.

## 🚀 Features

- Select from predefined stocks
- Enter stock quantity
- Calculate individual investment
- Calculate total portfolio value
- Display total stocks and quantity
- Show portfolio percentage
- Remove individual investments
- Clear entire portfolio
- Input validation
- Responsive web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Jinja2
